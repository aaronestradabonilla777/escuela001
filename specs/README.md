# Specs

Cada feature tiene una especificación breve con alcance, criterios observables, edge cases, invariantes, riesgos y evidencia.

1. Usa `_template.md` para nuevas features.
2. Asigna un ID estable con formato `SPEC-AAAA-NNN`.
3. Obtén aprobación explícita antes de implementar.
4. Documenta decisiones de arquitectura durables en `docs/` y enlázalas desde la spec.
5. No cambies IDs históricos; crea una nueva spec si el alcance cambia materialmente.

La spec inicial de Aula abierta es [SPEC-2026-001](SPEC-2026-001-aula-abierta.md).
